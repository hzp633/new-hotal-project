## 二、图的结构

### 1 / 2. 前台、后台模块图（树形结构）

三层树，自上而下：

```
        ┌─────────────────────────┐
        │  酒店预约管理系统        │   ← 第 1 层：系统 + 模块归属
        │      前台模块            │
        └───────────┬─────────────┘
     ┌──────┬───────┼───────┬──────┐
  用户认证  酒店首页  房型浏览  …  个人中心   ← 第 2 层：功能模块
     │
  ┌──┴──┬──────┐
 用   用    密    …                      ← 第 3 层：功能点（竖排文字）
 户   户    码
 注   登    找
 册   录    回
```

- **第 1 层**：矩形，两行文字，标注系统名与模块归属
- **第 2 层**：矩形，模块名（如"房型浏览模块"）
- **第 3 层**：窄条矩形，功能点**竖排文字**，顶部对齐、高度自适应
- 连线：正交折线（draw.io 自动形成树状总线）

### 3 / 4. 用例图（分层结构）

```
  角色 ──▶ 主用例 ──«include»──▶ 子用例
                    «extend» ◀── 扩展用例（箭头反向）
```

- **角色**：左侧 UML 小人；连线起点按层次分散，避免全部汇聚一点
- **主用例**（中列）：角色可直接触发的功能
- **子用例**（右列）：主用例细分出的具体操作
- **关系**：`«include»` 虚线箭头指向被包含用例；`«extend»` 虚线箭头指向基用例

## 四、与项目代码的一致性

图形内容与实际代码逐项核对：

- 前台模块 ← `frontend/src/router/index.js` 中 C 端路由（`views/c/*.vue`）
- 后台模块 ← 同文件中 B 端路由（`views/b/*.vue`，10 个页面）
- 后端接口 ← `backed/src/main/java/com/hotel/controller/*.java`（19 个 Controller）

其中 **支付退款** 模块（`AdminPaymentController` + `views/b/PaymentMgmt.vue`）在代码中已实现，故图中保留。

## 六、文件说明

| 文件 | 说明 |
|------|------|
| `drawio/*.drawio` | **主交付**，draw.io 可编辑源文件 |
| `preview/*.png` | 版式预览图 |
| `gen_drawio.py` | 生成 `.drawio` 的脚本，改内容后重跑即可 |
| `preview_drawio.py` | 版式校验 + 预览脚本（需本机安装 Graphviz） |
| `plantuml/*.puml` | 旧版 PlantUML 源码（早期版本，可忽略） |

> **改图两种方式**：
> 1. 直接在 draw.io 里拖拽编辑（推荐，所见即所得）；
> 2. 改 `gen_drawio.py` 里的 `FRONT` / `BACK` / `ADMIN_GROUPS` / `USER_GROUPS` 数据，运行 `python gen_drawio.py` 重新生成。
>
> 用例的 `«include»` / `«extend»` 关系：子用例写成字符串即为 `«include»`，写成 `("用例名", "extend")` 即为 `«extend»`。
